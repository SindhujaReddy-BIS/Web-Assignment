Web Assignment Project

 Project Overview

This project is a simple and responsive web page that demonstrates:

* Sticky Header on scroll
* Hero Section with gradient background
* Image Carousel with smooth scrolling
* Hover zoom effects on images

 Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

 ✨ Features

🔹 Sticky Header

* Header appears when user scrolls down
* Smooth transition effect

🔹 Hero Section

* Full screen layout
* Gradient background
* Centered text

🔹 Image Carousel

* Horizontal scrolling images
* Left & right navigation buttons
* Smooth scroll behavior

🔹 Hover Effects

* Images zoom on hover for better UI experience

🔹 Responsive Design

* Works on mobile, tablet, and desktop

 How to Run Locally

1. Download or clone the repository
2. Open index.html in any browser
